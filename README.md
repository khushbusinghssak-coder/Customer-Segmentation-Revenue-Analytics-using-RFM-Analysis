# Customer-Segmentation-Revenue-Analytics-using-RFM-Analysis
Analyzed retail customer purchase data using the RFM model (Recency, Frequency, Monetary) to segment customers into valuable groups like Champions, Loyal, and At Risk. Used Python for data cleaning and scoring, and built an interactive Power BI dashboard to track customer behavior, revenue insights, and top-performing segments.
 # Customer Segmentation & Revenue Analytics (RFM)

## Overview
This project uses the **RFM Model (Recency, Frequency, Monetary)** to analyze customer purchasing behavior and segment customers into meaningful business groups such as **Champions, Loyal Customers, Potential Loyalists, At Risk, and Lost Customers**.

The goal is to help businesses improve customer retention, increase revenue, and make data-driven marketing decisions.

---

## Objectives
- Analyze customer purchase patterns
- Segment customers using RFM methodology
- Identify top revenue-generating customers
- Track revenue by customer segment
- Build an interactive dashboard for decision-making

## Methodology

### 1. Data Cleaning
- Removed missing values
- Removed duplicates
- Converted date columns
- Created Revenue column

### 2. RFM Analysis
- **Recency** = Days since last purchase
- **Frequency** = Number of orders
- **Monetary** = Total spending

### 3. Customer Segmentation
Customers were grouped into:
- Champions
- Loyal Customers
- Potential Loyalists
- At Risk
- Lost Customers

### 4. Dashboard Creation
Built an interactive Power BI dashboard showing:
- Total Customers
- Total Revenue
- Top Customers
- Revenue by Segment
- Revenue by Product Category

---

## Key Insights
- Champions generated the highest revenue share
- Loyal customers formed the second strongest segment
- Top customers contributed significantly to total sales
- Some customers were identified as At Risk and Lost

---

## Business Recommendations
- Reward Champions with VIP offers
- Retain Loyal Customers using loyalty programs
- Re-engage At Risk customers with campaigns
- Win back Lost customers through discounts
